fm-contributions driven against the real github.com through the real gh CLI.
Each section stands up an isolated Firstmate home (own data/, state/, config/)
and runs the shipped bin/fm-contributions.sh and bin/fm-bearings-snapshot.sh.
The only wrapper around gh is a logger that execs /usr/bin/gh, so every
"forge read" line below is a request that actually went to github.com.
PRs used: 14337 (merged, two MEMBER reviews), 14448 (closed, never merged),
13788 (open, three failing lanes).
Two reading notes:
  * Section A's last block reprojects the record the NEW poll wrote, so both
    builds agree there; the real base/target contrast is section A2, where the
    base build does its own poll of the same merged PR.
  * Section G's first attempt is left in place but is void: its seed poll was
    rate-limited, so one record was missing. It was re-driven cleanly in the
    second G section at the end of this file.
